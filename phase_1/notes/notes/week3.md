## Week 3 


## Logical Operators

### and

Both conditions must be True.

### or

At least one condition must be True.

### not

Reverses a Boolean value.

## Things I Learned

- Programs can check multiple conditions together.
- Good software explains why an action succeeds or fails.
- Compound conditions make code more expressive.

## Day 2

Today I learned how to use `elif` to create multiple decision paths in Python. I discovered that Python stops checking conditions once it finds a match, making programs cleaner and easier to manage. I also connected this concept to AI systems, where software often makes a sequence of decisions before producing an output.

## Day 3

Today I learned nested conditional statements. Instead of writing one long condition with many `and` operators, I learned how to verify one condition before checking the next. I also applied this concept to AIOS by improving role assignment, user verification, football membership, and session management using nested logic.
