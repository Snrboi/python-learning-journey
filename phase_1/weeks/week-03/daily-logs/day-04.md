## 🎯 What I Learned
- Today I finally understood how while loops actually work.

Instead of memorizing the syntax, I learned to think of every loop in four parts:

Starting Point – where the loop begins.
Condition – what must remain true for the loop to continue.
Work – the task that repeats.
Update – the change made before checking the condition again.

One of the biggest lessons was understanding that after each iteration, the computer jumps back to the condition, not to the beginning of the program. The loop only continues if the condition is still true.

I also learned that a loop stops naturally when the condition becomes false because the program's state has changed.

## Key Takeaways
- Every loop has four essential parts.
- Variables change after every iteration.
- The condition controls whether the loop continues.
- Forgetting to update the loop variable can create an infinite loop.
- Loops are used to keep programs running until a condition changes.
