## While Loops

This was one of my biggest personal goals because loops had always
been challenging.

By the end of the week I understood:

-   Starting Point
-   Condition
-   Work
-   Update
-   Program flow during loops
-   Incrementing and decrementing
-   Infinite loops
-   State-driven execution

One of the biggest breakthroughs was realizing that after every
iteration, Python returns to the **condition**, not the beginning of the
program.

------------------------------------------------------------------------

# 💡 Biggest Concept Learned

## Application State

I learned that:

``` python
logged_in = True
```

means AIOS is active.

Changing it to:

``` python
logged_in = False
```

changes the application's state, causing the program to exit naturally.
