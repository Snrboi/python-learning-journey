## 🌟 Biggest Lesson

This week I learned that programming is not only about making code work—it's also about creating a good experience for the user.

Using `if` and `else` taught me that software should always communicate clearly by explaining both successful and unsuccessful outcomes instead of leaving users guessing.

I also began thinking more like a software engineer by documenting my work, versioning my project, and improving an existing application instead of constantly starting new ones.

---

## 🚧 Biggest Challenge

One of my biggest challenges this week was slowing down and carefully reading instructions. During one lesson, I accidentally submitted the Bug Detective solution instead of the mini project.

I also realized that building software involves more than writing code. Understanding project structure, versioning, documentation, and maintaining a long-term project like DeveloperOS were all new experiences that required a different way of thinking.
